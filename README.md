# Лабораторная работа 3

WPF-приложение на C# ищет корень `f(x)=0` методом дихотомии. Вычисления выполняются в программе; график строит Image-Charts без ключа.

## Запуск

На Windows откройте `WpfApp2.slnx` в Visual Studio и запустите проект. Нужен .NET 10 SDK; интернет требуется для графика.

## Ввод

Укажите `a < b`, формулу (например, `x^2+2*x-6`) и количество знаков после запятой: `3` означает точность `0,001`. Умножение пишите явно: `2*x`.

Для произвольной функции выборка не гарантирует обнаружения всех корней и разрывов. Выбирайте узкий непрерывный интервал.
