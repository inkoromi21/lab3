# Лабораторная работа №3

WPF-приложение строит график функции и ищет корень уравнения `f(x) = 0` методом дихотомии. Значения функции вычисляются в программе; график загружается через Image-Charts.

## Запуск

На Windows откройте `WpfApp2.slnx` в Visual Studio с .NET 10 SDK. Готовый файл для Windows x64 — `WpfApp2.exe`. Интернет нужен для построения графика.

## Использование

Введите границы `a < b`, формулу и число знаков после запятой от 0 до 15. Например, для `x^2+2*x-6` значение `3` задаёт точность `0,001`. Нажмите «Построить график» или «Найти корень».

Поддерживаются `+`, `-`, `*`, `/`, `^`, скобки, `x`, `pi`, `e`, а также `sin`, `cos`, `tan`, `sqrt`, `ln`, `log`, `exp`, `abs`. Умножение пишется явно: `2*x`. Углы задаются в радианах; `ln` — натуральный логарифм, `log` — десятичный.
